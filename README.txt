Jak wrzucić na serwer:
1. Rozpakuj plik ZIP.
2. Wejdź przez FTP lub panel hostingu.
3. Wgraj całą zawartość folderu peipei_complete_site do katalogu public_html, www albo htdocs.
4. Otwórz domenę w przeglądarce.

Co warto uzupełnić przed publikacją:
- podmienić link Buy PeiPei na prawdziwy link do DEX,
- podmienić link Chart na prawdziwy wykres,
- dodać link Telegram,
- dodać link X/Twitter,
- zmienić status Liquidity, gdy będzie potwierdzony.
